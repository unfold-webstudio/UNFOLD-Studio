# UNFOLD

### Digital experiences, unfolded.

UNFOLD is a creative web studio focused on building **animated, interactive and cinematic websites** for brands that want to be remembered.

We don't make pages.
We make worlds that unfold as you scroll — where every movement has a reason and every scroll tells a story.

## ✦ How a Site Unfolds

### 01 — Find the Story

We start with the brand and identify the one idea worth telling.

Everything on the page serves that idea.

### 02 — Design the Motion

Storyboards, cinematic visuals and scroll choreography are planned before development.

The motion is designed frame by frame to make the experience feel intentional.

### 03 — Build & Launch

Clean, responsive code brings the experience to life.

Every website is built to work smoothly across both mobile and desktop devices before being launched.
